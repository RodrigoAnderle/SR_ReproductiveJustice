# SR_ReproductiveJustice

This repository contains the files and part of the analysis performed in the Scoping Review about Reproductive Justice.

In the script folder are the codes to perform the analysis. They are numbered in the order of analysis. The complete analysis can be performed by sourcing the script "00_Main_Script.R".

The input information is available in the "raw" folder. We don't recommend editing this folder to avoid mistakes.

The results and subresults are archived in the "data" folder, which has the major results of the study.

The shiny folder is specifically used for the shiny app that facilitated the analysis of the results.
